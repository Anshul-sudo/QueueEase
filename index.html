Data Structures & Algorithms (DSA) Concepts Explained

1. Queue Abstract Data Type (FIFO)

Implements First-In, First-Out (FIFO) queue semantics. Arrival pushes customers to the rear (enqueue), while available servers pop from the front (dequeue) in guaranteed O(1) time.

2. Multi-Server Queue Topologies

Compares a Single Global Shared Queue (centralized FIFO dispatch) vs. Multiple Dedicated Queues with a greedy routing heuristic (assigning incoming customers to the shortest queue).

3. Workload Imbalance Analysis

Quantifies server load disparity: Imbalance = max(Busy Time) - min(Busy Time). Demonstrates how separate queues cause server starvation while others remain congested, whereas shared queues balance load.

4. Arrival Pattern Dynamics & Complexity

Analyzes waiting times and peak queue lengths across Regular, Random, and Burst arrival patterns. Overall simulation runs in O(N) time with O(N) space complexity.
